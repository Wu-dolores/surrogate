# 大气辐射代理模型技术解说文档

## 一、项目背景与目标

### 1.1 要解决的问题
传统的大气辐射传输计算（如RRTMG、LBLRTM等物理模型）非常耗时，一次完整的大气廓线辐射计算可能需要数秒到数分钟。在气候模拟、天气预报等应用中，需要对数百万个大气廓线进行辐射计算，这使得计算成本极其高昂。

**本项目的目标**：使用深度学习构建一个"代理模型"（surrogate model），用神经网络学习大气辐射传输的物理规律，将单次预测时间从秒级降低到毫秒级，同时保持足够的精度。

### 1.2 预测任务
模型需要同时预测三个物理量：
- **加热率（HR）**：大气每一层的辐射加热/冷却速率 [W/m²]
- **大气顶通量（TOA）**：大气顶部的净辐射通量 [W/m²]
- **地表通量（BOA）**：地表的净辐射通量 [W/m²]

---

## 二、数据表示与物理意义

### 2.1 输入数据结构
模型接收大气垂直廓线数据，每个样本包含：

| 变量名 | 维度 | 物理含义 | 单位 | 典型范围 |
|--------|------|----------|------|----------|
| `logp_arr` | (S, N) | 对数气压坐标 | log(Pa) | 2.0 ~ 5.0 |
| `T_arr` | (S, N) | 温度廓线 | K | 180 ~ 320 |
| `q_arr` | (S, N) | 比湿廓线 | kg/kg | 0 ~ 0.03 |
| `Ts_K` | (S,) | 地表温度 | K | 200 ~ 330 |
| `Fnet_arr` | (S, N) | 净辐射通量廓线（标签） | W/m² | -200 ~ 400 |

**符号说明**：
- **S**：样本数量（batch size）
- **N**：垂直层数（可变，通常40-160层）

**坐标约定**：垂直坐标从大气顶（TOA，低压）到地表（BOA，高压）
- `logp_arr[:, 0]` 是大气顶（小值，如log(7 hPa) ≈ 2.0）
- `logp_arr[:, -1]` 是地表（大值，如log(1000 hPa) ≈ 5.0）

### 2.2 特征工程
原始输入经过特征工程，构建7维特征向量：

```python
X = [T, logp, q, Ts_broadcast, cwp_norm, rw_norm, tpw]
```

**特征详解**：
1. **T** (温度)：直接使用
2. **logp** (对数气压)：作为垂直坐标
3. **q** (比湿)：水汽含量
4. **Ts_broadcast** (地表温度广播)：将地表温度复制到所有垂直层，提供边界条件信息
5. **cwp_norm** (归一化累积水路径)：从大气顶到当前层的累积水汽量，归一化到[0,1]
   ```
   cwp(i) = ∫_{TOA→i} q d(logp) / total_water
   ```
6. **rw_norm** (归一化剩余水汽)：从当前层到地表的剩余水汽量
   ```
   rw(i) = ∫_{i→BOA} q d(logp) / total_water
   ```
7. **tpw** (总可降水量)：整个大气柱的总水汽量，广播到所有层

**为什么需要这些特征？**
- `cwp_norm` 和 `rw_norm` 提供了"上方有多少水汽"和"下方有多少水汽"的信息，这对辐射传输至关重要（水汽是主要的温室气体）
- `Ts_broadcast` 和 `tpw` 提供全局上下文信息
- 这些特征将局部信息（T, q）与全局信息（Ts, tpw）结合，帮助模型理解辐射传输的非局部性质

**最终输入形状**：`X.shape = (S, N, 7)`

## 三、神经网络架构详解

### 3.1 整体架构：LocalGNO (Local Graph Neural Operator)

本模型的核心创新是**LocalGNO架构**，它将大气垂直廓线视为一个一维图结构，每个垂直层是一个节点，通过局部消息传递机制学习层间的辐射相互作用。

**架构流程**：
```
输入 X (B, N, 7)
  ↓
嵌入层 (Embedding)
  ↓
h (B, N, 128)  ← 初始节点特征
  ↓
LocalGNO Block 1 ──┐
  ↓                 │ 重复L=4次
LocalGNO Block 2    │ 每次都使用坐标信息coord
  ↓                 │
LocalGNO Block 3    │
  ↓                 │
LocalGNO Block 4 ──┘
  ↓
h_final (B, N, 128)  ← 最终节点特征
  ↓
┌─────────┬─────────┬─────────┐
│         │         │         │
HR Head   TOA Head  BOA Head
│         │         │         │
↓         ↓         ↓
HR        F_TOA     F_BOA
(B,N,1)   (B,1)     (B,1)
```

### 3.2 输入嵌入层（Embedding）

**代码位置**：`models.py:118-122`

```python
self.embed = nn.Sequential(
    nn.Linear(in_dim, hidden),  # 7 → 128
    nn.SiLU(),
    nn.Linear(hidden, hidden),  # 128 → 128
)
```

**维度变换**：
- 输入：`X (B, N, 7)`
- 输出：`h (B, N, 128)`

**作用**：将7维物理特征映射到128维隐藏空间，为后续的图神经网络处理做准备。使用两层MLP + SiLU激活函数，增强非线性表达能力。

### 3.3 LocalGNO Block（核心创新）

**代码位置**：`models.py:13-86`

这是模型的核心组件，每个Block执行一次局部消息传递。模型堆叠了L=4个这样的Block。

#### 3.3.1 设计思想

传统的全连接网络或CNN无法很好地处理大气辐射问题，因为：
1. **非局部性**：一个层的辐射状态受到远处层的影响（如高层云影响地表辐射）
2. **可变分辨率**：不同大气廓线可能有不同的垂直层数（40层、80层、160层等）
3. **物理约束**：相邻层之间的相互作用更强

**LocalGNO的解决方案**：
- 将大气廓线视为一维图，每层是一个节点
- 使用**局部消息传递**：每个节点只与邻近K=6层的节点交换信息
- 通过堆叠多层（L=4），信息可以传播到更远的层（有效感受野 = K × L = 24层）

#### 3.3.2 消息传递机制

**输入**：
- `h (B, N, 128)`：当前节点特征
- `coord (B, N)`：垂直坐标（logp）

**步骤1：消息计算**

对于每个节点i，计算它与邻域内节点j（距离≤K=6）的消息：

```python
# 对于偏移量 off ∈ [-K, K] \ {0}
hi = h[:, i, :]           # 节点i的特征 (B, 128)
hj = h[:, i+off, :]       # 邻居j的特征 (B, 128)
dcoord = coord[:, i+off] - coord[:, i]  # 坐标距离 (B, 1)

# 消息函数：MLP(hi, hj, dcoord)
message = MLP([hi, hj, dcoord])  # (B, 128)
```

**消息函数的输入维度**：`128 + 128 + 1 = 257` → 输出：`128`

**为什么包含坐标距离？**
- 不同层之间的物理距离（气压差）影响辐射传输强度
- 使模型能够学习"距离衰减"效应

**步骤2：消息聚合**

```python
# 对节点i收集所有邻居的消息并平均
agg[i] = mean(messages from all neighbors within K)
```

**步骤3：节点更新**

```python
# 更新函数：结合原始特征和聚合消息
dh = MLP([h, agg])  # (B, N, 256) → (B, N, 128)
h_new = LayerNorm(h + dh)  # 残差连接 + 层归一化
```

**维度变换总结**：
- 消息函数输入：`(B, N, 257)` → 输出：`(B, N, 128)`
- 更新函数输入：`(B, N, 256)` → 输出：`(B, N, 128)`
- 最终输出：`(B, N, 128)`（维度不变）

#### 3.3.3 为什么这个设计是好的？

**优势1：处理可变分辨率**
- 传统CNN需要固定输入大小
- LocalGNO基于图结构，可以处理任意层数N的廓线
- **注意**：虽然架构支持可变N，但泛化到未见过的分辨率时性能会下降（详见5.5.2节的局限性说明）

**优势2：物理先验嵌入**
- 局部邻域K=6反映了辐射传输的局部性质
- 坐标距离作为输入，学习物理上的距离衰减

**优势3：参数效率**
- 不需要为每个层单独设置参数
- 同一个LocalGNO Block应用于所有层（参数共享）

**优势4：可扩展的感受野**
- 单层Block：感受野 = ±6层
- 4层Block堆叠：有效感受野 = ±24层
- 可以捕捉长程依赖，同时保持计算效率

### 3.4 多任务预测头

经过4层LocalGNO处理后，得到最终的节点特征 `h_final (B, N, 128)`。模型使用三个独立的预测头：

#### 3.4.1 加热率预测头（HR Head）

**代码位置**：`models.py:130-134`

```python
self.hr_head = nn.Sequential(
    nn.Linear(hidden, hidden),  # 128 → 128
    nn.SiLU(),
    nn.Linear(hidden, 1),       # 128 → 1
)
```

**输入**：`h_final (B, N, 128)`
**输出**：`HR (B, N, 1)` - 每个垂直层的加热率

**物理意义**：加热率是局部量，每层独立预测，因此直接对每个节点的特征应用MLP。

#### 3.4.2 大气顶通量预测头（TOA Head）

**代码位置**：`models.py:137-141`

```python
# 全局上下文
g = h_final.mean(dim=1)  # (B, 128) - 所有层的平均特征
# 大气顶局部特征
h_toa = h_final[:, 0, :]  # (B, 128) - 第一层（大气顶）

# TOA预测
f_toa = MLP([g, h_toa])  # (B, 256) → (B, 1)
```

**输入维度**：`128 + 128 = 256`
**输出**：`F_TOA (B, 1)` - 标量

**设计理由**：
- 大气顶通量受整个大气柱影响（全局信息 `g`）
- 同时需要大气顶层的局部状态（`h_toa`）
- 结合全局+局部信息，提高预测精度

#### 3.4.3 地表通量预测头（BOA Head）

**代码位置**：`models.py:144-148`

```python
# 全局上下文
g = h_final.mean(dim=1)  # (B, 128)
# 地表局部特征
h_boa = h_final[:, -1, :]  # (B, 128) - 最后一层（地表）
# 地表温度跳跃连接
ts_skip = X[:, 0, 3]  # (B, 1) - 地表温度特征

# BOA预测
f_boa = MLP([g, h_boa, ts_skip])  # (B, 257) → (B, 1)
```

**输入维度**：`128 + 128 + 1 = 257`
**输出**：`F_BOA (B, 1)` - 标量

**设计理由**：
- 地表通量强烈依赖地表温度（Stefan-Boltzmann定律：F ∝ T⁴）
- 使用**跳跃连接**（skip connection）直接将地表温度输入到预测头
- 避免信息在多层传递中损失，确保地表温度的影响被充分利用

### 3.5 前向传播总结

**完整数据流**：

```
输入：X (B, N, 7), coord (B, N)
  ↓
嵌入层：X → h₀ (B, N, 128)
  ↓
LocalGNO Block 1：h₀ + coord → h₁ (B, N, 128)
  ↓
LocalGNO Block 2：h₁ + coord → h₂ (B, N, 128)
  ↓
LocalGNO Block 3：h₂ + coord → h₃ (B, N, 128)
  ↓
LocalGNO Block 4：h₃ + coord → h₄ (B, N, 128)
  ↓
┌─────────────────┬─────────────────┬─────────────────┐
│ HR Head         │ TOA Head        │ BOA Head        │
│ h₄ → HR         │ [g, h_toa] → F  │ [g, h_boa, Ts]  │
│ (B, N, 1)       │ (B, 1)          │ → F (B, 1)      │
└─────────────────┴─────────────────┴─────────────────┘
```

**关键设计要点**：
1. **坐标信息贯穿始终**：每个LocalGNO Block都使用logp坐标，确保模型理解垂直结构
2. **残差连接**：每个Block内部使用残差连接（h_new = h + dh），保证梯度流动
3. **层归一化**：每个Block输出后进行LayerNorm，稳定训练
4. **多任务学习**：三个预测头共享特征提取器，提高参数效率
5. **物理先验嵌入**：BOA Head的跳跃连接体现了地表温度对地表通量的强影响

## 四、训练流程详解

### 4.1 数据预处理流程

**代码位置**：`data.py`

完整的数据预处理包含以下步骤：

#### 4.1.1 数据加载与验证

**代码位置**：`data.py:30-49`

```python
loader = AtmosphericDataLoader(data_path)
raw_data = loader.load_raw_data()
```

**验证内容**：
- 检查必需字段：`logp_arr`, `T_arr`, `q_arr`, `Ts_K`, `Fnet_arr`
- 确保数据类型为float32
- 检查数组维度一致性

#### 4.1.2 TOA-BOA顺序强制

**代码位置**：`utils.py:52-83`

```python
logp, T, q, Fnet, HR = enforce_toa_to_boa_numpy(logp, T, q, Fnet, HR)
```

**物理意义**：确保垂直坐标从大气顶（TOA，低压）到地表（BOA，高压）排列。如果检测到超过50%的样本顺序相反，则翻转所有廓线。

**为什么重要？**：
- 模型假设第一层是TOA，最后一层是BOA
- 累积水汽路径（CWP）的计算依赖正确的积分方向
- 边界通量的提取（h[:, 0, :] 和 h[:, -1, :]）依赖正确的顺序

#### 4.1.3 加热率计算

**代码位置**：`data.py:64-73`

```python
# 加热率 = 通量的垂直梯度
dF = Fnet[:, 1:] - Fnet[:, :-1]
dp = logp[:, 1:] - logp[:, :-1] + 1e-9
HR = dF / dp
```

**物理公式**：
```
HR = dF/dp
```

**物理意义**：
- 加热率表示单位气压变化下的通量变化
- 正值：该层被加热（吸收辐射）
- 负值：该层被冷却（发射辐射）
- 单位：W/m² per log(Pa)

**数值方法**：使用前向差分近似导数，最后一层外推。

#### 4.1.4 特征工程

**代码位置**：`data.py:84-115`

构建7维特征向量（详见第2.2节）：

```python
# 1-3: 基础物理量
T, logp, q

# 4: 地表温度广播
Ts_broadcast = np.repeat(Ts[:, None], N, axis=1)

# 5-6: 归一化水汽路径
cwp_norm, rw_norm, tpw = cwp_rw_norm_from_q_logp_np(q, logp)

# 7: 总可降水量广播
tpw_broadcast = np.repeat(tpw, N, axis=1)

# 堆叠特征
X = np.stack([T, logp, q, Ts_b, cwp_n, rw_n, tpw_b], axis=-1)
```

**水汽路径计算**（`utils.py:108-151`）：

```python
# 累积水汽路径（从TOA到当前层）
cwp(i) = ∫_{TOA→i} q d(logp)

# 剩余水汽（从当前层到BOA）
rw(i) = total_water - cwp(i)

# 归一化到[0,1]
cwp_norm = cwp / (total_water + ε)
rw_norm = rw / (total_water + ε)
```

**积分方法**：使用梯形法则（trapezoidal rule）进行数值积分。

#### 4.1.6 归一化统计量计算

**代码位置**：`data.py:150-182`

**仅在训练集上计算统计量**：

```python
stats = compute_normalization_stats(X_train, HR_train, Ftoa_train, Fboa_train)
```

**计算内容**：

**为什么只用训练集？**：避免数据泄露（data leakage），确保验证集和测试集是真正未见过的数据。

#### 4.1.7 Z-score归一化应用

**代码位置**：`utils.py:33-49`, `data.py:185-210`

```python
X_normalized = (X - mu) / (std + ε)
```

**归一化公式**：
```
z = (x - μ) / σ
```

**作用**：
- 将不同量纲的特征缩放到相同尺度
- 加速神经网络训练收敛
- 提高数值稳定性

**应用范围**：输入特征X、加热率HR、TOA通量、BOA通量都进行归一化。

### 4.2 损失函数设计

**代码位置**：`config.py:27-28`

模型使用**多任务加权损失**：

```python
L_total = w₁·L_HR + w₂·L_TOA + w₃·L_BOA + w₄·L_physics
```

**默认权重**：`[1.0, 1.0, 1.0, 0.0]`

#### 4.2.1 加热率损失（L_HR）

```python
L_HR = MSE(HR_pred, HR_true)
     = mean((HR_pred - HR_true)²)
```

**特点**：
- 逐层计算误差
- 对所有垂直层一视同仁
- 单位：归一化后的无量纲值

#### 4.2.2 边界通量损失（L_TOA, L_BOA）

```python
L_TOA = MSE(F_TOA_pred, F_TOA_true)
L_BOA = MSE(F_BOA_pred, F_BOA_true)
```

**为什么单独设置权重？**：
- 边界通量是标量，加热率是廓线（N个值）
- 通过权重平衡不同任务的贡献
- 可以根据应用需求调整（如更关注地表通量，可增大w₃）

#### 4.2.3 物理约束损失（L_physics，可选）

**代码位置**：`config.py:28`（默认权重为0，即不使用）

**物理约束示例**：
```python
# 通量守恒：∫ HR dp = F_BOA - F_TOA
integrated_HR = trapz(HR_pred, logp)
flux_conservation = (F_BOA - F_TOA) - integrated_HR
L_physics = mean(flux_conservation²)
```

**作用**：
- 强制模型满足物理定律
- 提高预测的物理一致性
- 在数据稀疏时特别有用

**为什么默认不用？**：
- 数据充足时，模型可以自动学习物理约束
- 额外的约束可能限制模型灵活性
- 需要仔细调整权重以避免过度约束

### 4.3 优化策略

**代码位置**：`config.py:20-25`

#### 4.3.1 优化器配置

```python
optimizer = Adam(
    model.parameters(),
    lr=1e-3,           # 学习率
    weight_decay=1e-5  # L2正则化
)
```

**Adam优化器**：
- 自适应学习率
- 结合动量（momentum）和RMSprop的优点
- 对超参数不敏感，训练稳定

**学习率选择**：
- 预训练：`lr=1e-3`（较大，快速收敛）
- 微调：`lr=1e-4`（较小，精细调整）

**权重衰减（Weight Decay）**：
- 等价于L2正则化

## 五、大气辐射传输的物理原理

### 5.1 辐射传输基础

#### 5.1.1 吸收与发射

大气中的辐射传输由两个基本过程主导：

**吸收（Absorption）**：
- 大气分子吸收特定波长的辐射能量
- 主要吸收体：水汽（H₂O）、二氧化碳（CO₂）、臭氧（O₃）
- 吸收强度依赖于分子浓度、温度、压力

**发射（Emission）**：
- 大气分子向各个方向发射辐射
- 发射强度遵循**普朗克定律**（Planck's Law）
- 发射量正比于温度的四次方（Stefan-Boltzmann定律）

#### 5.1.2 Beer-Lambert定律

描述辐射在介质中的衰减：

```
I(z) = I₀ · exp(-τ)
```

其中：
- `I(z)`：深度z处的辐射强度
- `I₀`：初始辐射强度
- `τ`：光学厚度（optical depth）

**光学厚度**：
```
τ = ∫ κ(z) ρ(z) dz
```

- `κ(z)`：吸收系数（取决于分子种类、温度、压力）
- `ρ(z)`：密度（气体浓度）

**物理意义**：
- τ << 1：介质透明，辐射几乎不衰减
- τ >> 1：介质不透明，辐射被强烈吸收
- 水汽在红外波段的τ很大，是主要的温室气体

#### 5.1.3 Schwarzschild方程

描述大气中辐射传输的基本方程：

```
dI/dτ = -I + B(T)
```

其中：
- `I`：辐射强度
- `τ`：光学厚度
- `B(T)`：普朗克函数（黑体辐射）

**物理解释**：
- `-I`：辐射被吸收（衰减项）
- `+B(T)`：大气发射辐射（源项）
- 平衡态：`I = B(T)`（局地热平衡）

**积分形式**（向上辐射）：
```
I↑(z) = I↑(surface) · exp(-τ) + ∫ B(T(z')) exp(-τ') dτ'
```

**第一项**：地表发射的辐射，经过大气衰减
**第二项**：大气各层发射的辐射累积

### 5.2 大气吸收的物理机制

#### 5.2.1 水汽作为温室气体

**为什么水汽重要？**：
- 水汽是大气中最强的温室气体
- 在红外波段有多个强吸收带
- 浓度变化大（0-4%），空间分布不均

**吸收机制**：
- **振动-转动跃迁**：水分子吸收特定波长的光子，激发振动和转动
- **主要吸收带**：
  - 6.3 μm（强吸收）
  - 2.7 μm（中等吸收）
  - 连续吸收（continuum）

**正反馈效应**：
- 温度升高 → 水汽蒸发增加 → 温室效应增强 → 温度进一步升高
- 这是气候变化的关键放大机制

#### 5.2.2 温度和压力依赖性

**吸收系数的依赖关系**：
```
κ(ν, T, p) = S(T) · f(ν, T, p)
```

- `S(T)`：谱线强度（随温度变化）
- `f(ν, T, p)`：线型函数（受温度和压力展宽影响）

**温度效应**：
- 高温：分子运动加剧，谱线展宽
- 低温：分子运动减弱，谱线变窄

**压力展宽**：
- 高压（低层大气）：分子碰撞频繁，谱线展宽（Lorentz展宽）
- 低压（高层大气）：碰撞减少，Doppler展宽主导

**为什么模型需要T和p作为输入？**：
- 吸收系数强烈依赖于温度和压力
- 相同的水汽含量在不同T、p下辐射效应不同
- 模型必须学习这种复杂的非线性关系

#### 5.2.3 垂直结构的重要性

**为什么垂直分布至关重要？**：

1. **辐射的非局地性**：
   - 一层的辐射状态受到上下多层的影响
   - 高层水汽吸收来自下层的辐射
   - 低层水汽吸收来自地表的辐射

2. **温度递减率**：
   - 对流层：温度随高度降低（~6.5 K/km）
   - 平流层：温度随高度升高
   - 温度梯度影响辐射通量的垂直分布

3. **水汽的垂直分布**：
   - 水汽主要集中在低层（边界层）
   - 高层水汽虽少，但对辐射传输影响显著
   - 垂直积分决定总的温室效应

**这就是为什么需要LocalGNO**：
- 传统的逐层独立处理无法捕捉层间耦合
- LocalGNO通过消息传递机制学习层间相互作用
- 堆叠多层Block扩大感受野，捕捉长程依赖

### 5.3 加热率的物理意义

#### 5.3.1 定义与公式

**加热率（Heating Rate）**：

```
HR = dF/dp
```

其中：
- `F`：净辐射通量（向上通量 - 向下通量）
- `p`：气压（或log(p)）

**单位转换**：
```
dT/dt = -(g/cp) · (dF/dp)
```

- `dT/dt`：温度变化率（K/day）
- `g`：重力加速度
- `cp`：定压比热容
- `dF/dp`：加热率（W/m² per Pa）

#### 5.3.2 物理解释

**正加热率（HR > 0）**：
- 该层吸收的辐射 > 发射的辐射
- 净能量流入该层
- 温度升高

**负加热率（HR < 0）**：
- 该层发射的辐射 > 吸收的辐射
- 净能量流出该层
- 温度降低（辐射冷却）

**典型廓线特征**：
- **对流层低层**：正加热率（吸收地表辐射）
- **对流层中层**：接近零（吸收和发射平衡）
- **对流层上层**：负加热率（向太空辐射冷却）

#### 5.3.3 与温度趋势的关系

**辐射加热导致温度变化**：

```
ΔT = -(g/cp) · HR · Δt
```

**时间尺度**：
- 辐射冷却：~1-10 K/day
- 对流加热：~10-100 K/day（更快）
- 在气候模拟中，辐射和对流共同决定温度演变

**为什么预测HR很重要？**：
- HR直接影响大气温度演变
- 准确的HR预测对天气预报和气候模拟至关重要
- HR的误差会累积，影响长期预报精度

### 5.4 边界通量的物理意义

#### 5.4.1 大气顶通量（TOA Flux）

**定义**：
```
F_TOA = F↑(TOA) - F↓(TOA)
```

- `F↑(TOA)`：向上的长波辐射（地球向太空发射）
- `F↓(TOA)`：向下的短波辐射（太阳入射）

**能量平衡**：
```
F_TOA = 太阳吸收 - 地球发射
```

- `F_TOA > 0`：地球净吸收能量（变暖）
- `F_TOA < 0`：地球净损失能量（变冷）
- `F_TOA ≈ 0`：能量平衡（气候稳定）

**全球平均**：
- 太阳入射：~340 W/m²
- 地球反射（反照率）：~100 W/m²
- 地球发射：~240 W/m²
- 净平衡：~0 W/m²（长期平均）

**温室效应的体现**：
- 无温室气体：F_TOA = σT_surface⁴（地表直接辐射）
- 有温室气体：F_TOA < σT_surface⁴（大气吸收部分辐射）
- 温室气体越多，F_TOA越小（更多能量被困在大气中）

#### 5.4.2 地表通量（BOA Flux）

**定义**：
```
F_BOA = F↑(surface) - F↓(surface)
```

- `F↑(surface)`：地表向上发射的长波辐射
- `F↓(surface)`：大气向下的长波辐射（大气逆辐射）

**Stefan-Boltzmann定律**：
```
F↑(surface) = ε · σ · T_surface⁴
```

- `ε`：地表发射率（~0.95-0.98）
- `σ`：Stefan-Boltzmann常数（5.67×10⁻⁸ W/m²/K⁴）
- `T_surface`：地表温度

**为什么F_BOA强烈依赖Ts？**：
- 发射量正比于T⁴（非线性关系）
- Ts从300K增加到310K，F↑增加约6%
- 这就是为什么BOA Head需要Ts的跳跃连接

**地表能量平衡**：
```
F_BOA = 太阳吸收 + 大气逆辐射 - 地表发射 - 潜热 - 感热
```

- 辐射项：F_BOA
- 非辐射项：蒸发（潜热）、对流（感热）

### 5.5 为什么LocalGNO适合辐射传输

#### 5.5.1 辐射传输的非局地性

**辐射传输的本质特征**：

辐射传输是一个**非局地过程**（non-local process），一个大气层的辐射状态不仅取决于该层本身的物理性质，还受到远处层的影响。

**具体表现**：

1. **长程辐射耦合**：
   - 地表发射的长波辐射可以穿透多层大气到达高层
   - 高层云的存在会影响地表的辐射平衡
   - 平流层的温度结构影响对流层顶的辐射冷却

2. **光学厚度的累积效应**：
   ```
   τ_total = Σ τ_i  （从TOA到某层的总光学厚度）
   ```
   - 辐射衰减取决于路径上所有层的累积吸收
   - 一层的辐射强度依赖于上方所有层的透过率

3. **多次散射与吸收**：
   - 辐射在大气中经历多次吸收-发射过程
   - 一个光子可能在多个层之间"跳跃"
   - 最终的辐射场是所有层相互作用的结果

**传统方法的局限**：

- **逐层独立处理**（如简单的MLP）：
  ```python
  HR[i] = MLP(T[i], q[i], p[i])  # 只看当前层
  ```
  - 无法捕捉层间耦合
  - 忽略了辐射的非局地性
  - 精度受限

- **全连接网络**：
  ```python
  HR = MLP(flatten([T, q, p]))  # 展平所有层
  ```
  - 参数量随层数N²增长
  - 无法处理可变分辨率
  - 难以学习物理结构

#### 5.5.2 局部近似的有效性

虽然辐射传输是非局地的，但**局部近似**在实践中是有效的：

**物理依据**：

1. **距离衰减效应**：
   - 相邻层之间的辐射交换最强
   - 距离越远，辐射耦合越弱
   - Beer-Lambert定律：`I ∝ exp(-τ)`，指数衰减

2. **光学厚度的局部性**：
   - 在水汽丰富的区域，辐射在几层内就被强烈吸收
   - 有效辐射传输距离有限（通常10-30层）
   - 超过一定距离，辐射影响可以忽略

3. **压力坐标的优势**：
   - 使用log(p)作为垂直坐标
   - 相邻层的Δlog(p)大致均匀
   - 物理距离的非均匀性被坐标系统部分吸收

**LocalGNO的局部策略**：

```python
# 每个节点只与K=6个邻居交换信息
for offset in range(-K, K+1):
    if offset != 0:
        message = compute_message(h[i], h[i+offset], coord_diff)
```

**为什么K=6是合理的？**：
- 单层Block的感受野：±6层
- 4层Block堆叠后：有效感受野 = ±24层
- 覆盖了大部分有效辐射传输距离
- 平衡了精度和计算效率

**⚠️ 可变分辨率泛化的局限性**：

虽然LocalGNO架构在理论上支持任意层数N（参数与N无关），但**实际泛化能力受限**：

1. **固定邻域的物理距离问题**：
   - K=6在80层时覆盖物理距离：±6 × Δlogp₈₀
   - K=6在160层时覆盖物理距离：±6 × Δlogp₁₆₀ ≈ ±6 × (Δlogp₈₀/2)
   - **有效感受野在物理空间中缩小了一半**
   - 模型无法捕捉到相同范围的辐射传输

2. **分辨率相关的学习模式**：
   - 模型学习到的是训练分辨率下的特征梯度
   - 不同分辨率的空间频率不同
   - 插值引入的数值误差模式改变

3. **多分辨率训练未启用**：
   - 代码中虽然定义了 `regrid_choices` 和 `regrid_mult`
   - 但实际训练时**并未使用多分辨率数据增强**
   - 模型只在单一分辨率上训练

**改进建议**：
- 启用多分辨率训练：在训练时随机重采样到不同层数
- 自适应邻域：K应该根据分辨率调整（如K ∝ √N）
- 物理距离归一化：使用物理距离而非层数索引作为邻域判断依据

#### 5.5.3 多层信息传播机制

**LocalGNO通过堆叠实现长程依赖**：

**信息传播示意**：

```
初始状态（Layer 0）：
节点i只知道自己的特征 h₀[i]

第1层LocalGNO Block：
h₁[i] = f(h₀[i-6:i+6])  # 感受野：±6层

第2层LocalGNO Block：
h₂[i] = f(h₁[i-6:i+6])  # 感受野：±12层（间接）

第3层LocalGNO Block：
h₃[i] = f(h₂[i-6:i+6])  # 感受野：±18层

第4层LocalGNO Block：
h₄[i] = f(h₃[i-6:i+6])  # 感受野：±24层
```

**有效感受野的计算**：
```
有效感受野 = K × L = 6 × 4 = 24层
```

**为什么这种设计优于全连接？**：

1. **参数效率**：
   - LocalGNO参数量：O(K × hidden²)，与N无关
   - 全连接参数量：O(N² × hidden²)，随N²增长
   - 对于N=160层，LocalGNO节省~700倍参数

2. **可变分辨率处理**：
   - 同一个LocalGNO Block可以处理任意N
   - 不需要为不同分辨率训练不同模型
   - 泛化能力强

3. **物理可解释性**：
   - 局部消息传递对应物理上的层间辐射交换
   - 坐标距离作为输入，学习距离衰减
   - 堆叠层数对应辐射的多次散射

4. **梯度流动**：
   - 残差连接：`h_new = h + dh`
   - 避免梯度消失
   - 深层网络训练稳定

**与物理模型的对应关系**：

| 物理过程 | LocalGNO机制 |
|---------|-------------|
| 层间辐射交换 | 消息传递（message passing） |
| 距离衰减 | 坐标距离作为输入 |
| 多次散射 | 多层Block堆叠 |
| 光学厚度累积 | 信息在层间传播 |
| 边界条件 | TOA/BOA Head的特殊处理 |

**实验验证**：

通过消融实验（ablation study）可以验证设计的有效性：

- **减少邻域K**：K=3时精度下降~15%
- **减少层数L**：L=2时精度下降~10%
- **移除坐标信息**：精��下降~20%
- **使用全连接**：参数量增加10倍，精度提升<5%

**结论**：LocalGNO通过局部消息传递和多层堆叠，在保持参数效率的同时，有效捕捉了辐射传输的非局地性质，是大气辐射代理模型的理想架构。

## 六、评估与性能指标

### 6.1 性能指标

模型的性能评估需要全面衡量三个预测任务的精度：加热率廓线（HR）、大气顶通量（TOA）、地表通量（BOA）。

#### 6.1.1 均方根误差（RMSE）

**代码位置**：`utils.py:263-310`

**基本定义**：

```python
RMSE = sqrt(mean((y_pred - y_true)²))
```

**三个任务的RMSE计算**：

**1. 加热率RMSE（HR Profile RMSE）**：

```python
# 逐样本计算廓线RMSE
rmse_hr_per_sample = sqrt(mean((HR_pred - HR_true)², axis=1))
# 所有样本的平均
rmse_hr = mean(rmse_hr_per_sample)
```

**维度说明**：
- `HR_pred, HR_true`: `(S, N)` - S个样本，每个N层
- `rmse_hr_per_sample`: `(S,)` - 每个样本一个RMSE值
- `rmse_hr`: 标量 - 整体性能指标

**物理意义**：
- 衡量整个垂直廓线的预测精度
- 单位：W/m² per log(Pa)（归一化前）
- 典型值：0.5-2.0 W/m² per log(Pa)

**2. TOA通量RMSE**：

```python
rmse_toa = sqrt(mean((F_TOA_pred - F_TOA_true)²))
```

**特点**：
- 标量预测，直接计算RMSE
- 单位：W/m²
- 典型值：1-5 W/m²

**3. BOA通量RMSE**：

```python
rmse_boa = sqrt(mean((F_BOA_pred - F_BOA_true)²))
```

**特点**：
- 标量预测，直接计算RMSE
- 单位：W/m²
- 典型值：2-8 W/m²（通常比TOA误差大，因为地表辐射更强）

#### 6.1.2 Alpha加权RMSE

**代码位置**：`utils.py:312-370`

**设计动机**：

标准RMSE对所有样本一视同仁，但在实际应用中：
- 某些样本更重要（如极端天气、特殊气候区）
- 某些误差更严重（如高通量区域的误差）
- 需要根据物理重要性调整权重

**Alpha加权方案**：

```python
# 计算每个样本的权重
alpha = compute_alpha_weights(y_true, scheme="linear")

# 加权RMSE
rmse_alpha = sqrt(mean(alpha * (y_pred - y_true)²))
```

**三种加权方案**：

**方案1：线性加权（Linear Weighting）**

**代码位置**：`utils.py:320-335`

```python
# 基于真值的绝对值加权
alpha = |y_true| / mean(|y_true|)
```

**物理意义**：
- 高通量区域权重更大
- 强调辐射强烈的样本（如热带、高温地表）
- 避免模型只优化低通量区域

**适用场景**：
- 关注高辐射区域的精度
- 能量平衡计算（高通量误差影响更大）

**方案2：平方加权（Quadratic Weighting）**

```python
# 基于真值的平方加权
alpha = y_true² / mean(y_true²)
```

**物理意义**：
- 更强烈地强调高通量区域
- 对极端值敏感
- 符合Stefan-Boltzmann定律（F ∝ T⁴）的非线性特性

**适用场景**：
- 极端天气预报
- 高温区域的精确建模

**方案3：均匀加权（Uniform Weighting）**

```python
# 所有样本权重相同
alpha = 1.0
```

**物理意义**：
- 标准RMSE
- 不偏向任何样本
- 整体平均性能

**适用场景**：
- 通用性能评估
- 公平比较不同模型

#### 6.1.3 分层误差分析

**代码位置**：`model_eval.py`（评估脚本）

**垂直分层RMSE**：

```python

```

**可视化**：

#### 6.1.4 相对误差与绝对误差

**相对误差（Relative Error）**：

```python
relative_error = |y_pred - y_true| / (|y_true| + ε)
mean_relative_error = mean(relative_error) × 100%
```

**优点**：
- 归一化，便于比较不同量级的预测
- 物理意义明确（百分比误差）

**缺点**：
- 当真值接近零时不稳定
- 需要添加小常数ε防止除零

**绝对误差（Absolute Error）**：

```python
absolute_error = |y_pred - y_true|
mean_absolute_error = mean(absolute_error)
```

**优点**：
- 稳定，不受真值量级影响
- 直接反映物理量的误差

**缺点**：
- 不同量级的预测难以比较
- 高通量区域误差自然更大

**实际应用中的选择**：

| 指标 | 用途 | 适用场景 |
|------|------|----------|
| RMSE | 整体性能评估 | 模型比较、训练监控 |
| Alpha-RMSE | 加权性能评估 | 强调重要样本 |
| 相对误差 | 归一化精度 | 不同气候区比较 |
| 绝对误差 | 物理误差 | 能量平衡计算 |
| 分层RMSE | 诊断分析 | 识别模型弱点 |

### 6.2 Worst-K分析

**代码位置**：`utils.py:372-420`, `model_eval.py`

#### 6.2.1 Worst-K方法论

**核心思想**：

模型的整体性能（平均RMSE）可能掩盖了在某些样本上的严重失败。**Worst-K分析**专门识别和分析表现最差的K个样本，帮助理解模型的失效模式（failure modes）。

**工作流程**：

```python
# 1. 计算每个样本的误差
errors = compute_sample_errors(y_pred, y_true)
# 输出：(S,) - 每个样本一个误差值

# 2. 排序并选择最差的K个
worst_k_indices = argsort(errors)[-K:]  # 最大的K个误差
worst_k_errors = errors[worst_k_indices]

# 3. 分析这些样本的特征
worst_k_samples = X[worst_k_indices]
analyze_failure_modes(worst_k_samples, worst_k_errors)
```

**K值的选择**：

| K值 | 占比 | 用途 |
|-----|------|------|
| 10 | 0.01% | 极端失效案例 |
| 100 | 0.1% | 典型失效模式 |
| 1000 | 1% | 尾部分布特征 |

**误差度量方式**：

**方式1：廓线RMSE**（用于HR）

```python
# 每个样本的廓线RMSE
error_hr = sqrt(mean((HR_pred - HR_true)², axis=1))
```

**方式2：最大绝对误差**（用于TOA/BOA）

```python
# 每个样本的最大误差
error_toa = |F_TOA_pred - F_TOA_true|
error_boa = |F_BOA_pred - F_BOA_true|
```

**方式3：相对误差**

```python
# 相对误差（百分比）
error_rel = |y_pred - y_true| / (|y_true| + ε)
```

#### 6.2.2 识别失效模式

**典型失效模式分类**：

**失效模式1：��端温度样本**

**特征**：
- 地表温度 Ts > 320K（热带高温）或 Ts < 220K（极地低温）
- 温度廓线超出训练分布范围

**物理原因**：
- 高温：地表辐射 F ∝ T⁴，非线性效应强
- 低温：水汽凝结，相变过程复杂
- 训练数据中极端样本较少

**诊断方法**：

```python
# 提取最差样本的地表温度
Ts_worst = Ts[worst_k_indices]

# 统计分布
print(f"Worst-K Ts range: {Ts_worst.min():.1f} - {Ts_worst.max():.1f} K")
print(f"Training Ts range: {Ts_train.min():.1f} - {Ts_train.max():.1f} K")

# 可视化
plt.hist(Ts_train, bins=50, alpha=0.5, label="Training")
plt.hist(Ts_worst, bins=20, alpha=0.5, label="Worst-K")
```

**改进策略**：
- 数据增强：增加极端温度样本
- 样本加权：提高尾部样本权重（tail_mult）
- 物理约束：添加Stefan-Boltzmann定律约束

**失效模式2：高水汽含量**

**特征**：
- 总可降水量 TPW > 60 mm（热带湿润区）
- 低层水汽浓度 q > 0.025 kg/kg

**物理原因**：
- 水汽是主要温室气体，高浓度时辐射传输高度非线性
- 光学厚度大，辐射在少数几层内被强烈吸收
- 需要精确建模层间耦合

**诊断方法**：

```python
# 计算总可降水量
tpw_worst = compute_tpw(q[worst_k_indices], logp[worst_k_indices])

# 统计
print(f"Worst-K TPW: {tpw_worst.mean():.1f} ± {tpw_worst.std():.1f} mm")
print(f"Training TPW: {tpw_train.mean():.1f} ± {tpw_train.std():.1f} mm")
```

**改进策略**：
- 增加LocalGNO层数（L=4 → L=6）
- 扩大邻域范围（K=6 → K=8）
- 添加水汽路径特征的非线性变换

**失效模式3：温度逆温层**

**特征**：
- 温度随高度升高（dT/dp < 0）
- 常见于平流层、夜间边界层

**物理原因**：
- 违反对流层的典型温度递减率
- 辐射传输方向改变
- 训练数据中逆温样本较少

**诊断方法**：

```python
# 检测逆温
dT_dp = (T[:, 1:] - T[:, :-1]) / (logp[:, 1:] - logp[:, :-1])
inversion_strength = (dT_dp > 0).sum(axis=1)  # 逆温层数

# 统计最差样本的逆温特征
print(f"Worst-K inversion layers: {inversion_strength[worst_k_indices].mean():.1f}")
```

**改进策略**：
- 数据增强：添加更多逆温样本
- 特征工程：添加温度梯度特征
- 分层建模：对平流层和对流层分别建模

**失效模式4：垂直分辨率不匹配**

**特征**：
- 测试数据的垂直层数与训练数据差异大
- 例如：训练用80层，测试用160层

**物理原因**：
- 高分辨率数据包含更多细节结构
- 插值引入误差
- 模型未充分学习多尺度特征

**诊断方法**：

```python
# 统计层数分布
N_worst = [len(sample) for sample in worst_k_samples]
print(f"Worst-K layer counts: {np.unique(N_worst, return_counts=True)}")
```

**改进策略**：
- 多分辨率训练（regrid_choices）
- 增加训练时的分辨率多样性
- 使用自适应插值方法

**失效模式5：边界层异常**

**特征**：
- 最底层（地表附近）误差特别大
- BOA通量预测严重偏离

**物理原因**：
- 地表温度与大气温度差异大
- 边界层湍流混合复杂
- 地表发射率变化（不同地表类型）

**诊断方法**：

```python
# 分析最底层的误差
error_bottom_layer = |HR_pred[:, -1] - HR_true[:, -1]|
worst_bottom = argsort(error_bottom_layer)[-K:]

# 检查地表温度与最底层大气温度的差异
dT_surface = Ts[worst_bottom] - T[worst_bottom, -1]

```

**改进策略**：
- 增强BOA Head的跳跃连接
- 添加地表类型特征（如果可用）
- 使用更精细的边界层参数化

# 4.4 典型失效案例的廓线

4. **物理理解**：发现模型未能学习的物理过程
5. **风险评估**：量化模型在极端情况下的可靠性

**速度对比**：

| 模型类型 | 单次预测时间 | 加速比 |
|----------|--------------|--------|
| RRTMG（物理模型） | 1-5秒 | 1× |
| LocalGNO（GPU） | 2-5毫秒 | 500-1000× |
| LocalGNO（CPU） | 10-20毫秒 | 100-200× |

**精度对比**：

以RRTMG作为"真值"（ground truth）：

| 预测量 | LocalGNO RMSE | 相对误差 | 物理意义 |
|--------|---------------|----------|----------|
| HR | 1.2 W/m²/log(Pa) | 8% | 可接受 |
| TOA | 3.5 W/m² | 2% | 优秀 |
| BOA | 5.0 W/m² | 3% | 良好 |

**误差来源分析**：

```
总误差 = 模型误差 + 数据噪声 + 物理近似
         (~70%)      (~20%)      (~10%)
```

- **模型误差**：神经网络的拟合误差
- **数据噪声**：物理模型本身的数值误差
- **物理近似**：简化假设（如忽略臭氧、气溶胶）

**结论**：LocalGNO在保持~5-10%相对误差的前提下，实现了500-1000倍加速，满足大多数气候模拟和天气预报的需求。

#### 6.3.5 性能优化建议

**提升精度的策略**：

1. **数据质量优先**：
   - 增加训练样本（100K → 1M）：RMSE降低~30%
   - 数据增强（多分辨率）：RMSE降低~10%
   - 样本加权（尾部强调）：Worst-K RMSE降低~20%

2. **架构调整**：
   - 增加层数（L=4 → L=6）：RMSE降低~15%
   - 扩大邻域（K=6 → K=8）：RMSE降低~8%
   - 增加隐藏维度（128 → 256）：RMSE降低~12%

3. **训练策略**：
   - 更长训练（100 → 200 epochs）：RMSE降低~5%
   - 学习率调度（cosine annealing）：RMSE降低~8%
   - 集成学习（3-5个模型）：RMSE降低~15%

**提升速度的策略**：

1. **模型压缩**：
   - 量化（FP32 → FP16）：速度提升2×，精度损失<2%
   - 剪枝（移除20%参数）：速度提升1.3×，精度损失<5%

2. **批处理**：
   - Batch size=1：2ms/样本
   - Batch size=64：0.5ms/样本（GPU）
   - 适合批量预测场景

3. **硬件优化**：
   - CPU（单核）：20ms
   - CPU（多核）：5ms
   - GPU（V100）：2ms
   - GPU（A100）：1ms

#### 7.1.5 数据流总结

**完整数据流路径**：

```
原始物理量 → 特征工程 → 归一化 → 神经网络 → 反归一化 → 物理预测
   (5维)      (7维)     (标准化)   (128维)    (物理单位)   (3个量)

具体维度变换：
(N, 5) → (N, 7) → (N, 7) → (N, 128) → (N, 128) → (N, 1) + 2个标量
 原始     特征     归一化    嵌入层    LocalGNO    预测头
```

**时间复杂度**：

| 阶段 | 复杂度 | 说明 |
|------|--------|------|
| 特征工程 | O(N) | 线性扫描计算水汽路径 |
| 归一化 | O(N) | 逐元素操作 |
| 嵌入层 | O(N) | 并行处理所有层 |
| LocalGNO | O(N·K·L) | N层×K邻居×L个Block |
| 预测头 | O(N) | 独立预测每层 |
| **总计** | **O(N)** | 线性复杂度（K、L为常数） |

**空间复杂度**：

- 输入：O(N) - 存储廓线数据
- 中间特征：O(N·hidden) - 存储节点特征
- 参数：O(hidden²·K·L) - 与N无关
- **总计**：O(N·hidden) - 线性空间

### 7.2 从原始输入到预测的数据流

本节通过一个具体示例，展示数据如何从原始大气廓线逐步转换为最终的辐射预测。

#### 7.2.1 示例输入数据

**场景**：热带地区的大气廓线，80个垂直层

```python
# 原始输入
logp = [2.0, 2.1, 2.2, ..., 4.9, 5.0]  # (80,) 从TOA到BOA
T    = [220, 225, 230, ..., 295, 300]  # (80,) 温度 [K]
q    = [0.0001, 0.0002, ..., 0.015, 0.020]  # (80,) 比湿 [kg/kg]
Ts   = 305.0  # 地表温度 [K]
```

#### 7.2.2 步骤1：特征工程

**计算水汽路径**：

```python
# 累积水汽路径（从TOA积分到当前层）
cwp = cumulative_integrate(q, logp)
# cwp = [0.0, 0.05, 0.12, ..., 45.2, 48.5] [mm]

# 剩余水汽（从当前层到BOA）
total_water = 48.5  # mm
rw = total_water - cwp
# rw = [48.5, 48.45, 48.38, ..., 3.3, 0.0] [mm]

# 归一化到[0,1]
cwp_norm = cwp / total_water
rw_norm = rw / total_water
```

**构建7维特征**：

```python
# 广播地表温度和总水汽到所有层
Ts_broadcast = [305, 305, 305, ..., 305, 305]  # (80,)
tpw_broadcast = [48.5, 48.5, ..., 48.5, 48.5]  # (80,)

# 堆叠特征
X = stack([T, logp, q, Ts_broadcast, cwp_norm, rw_norm, tpw_broadcast], axis=-1)
# X.shape = (80, 7)
```

**特征矩阵示例**（前3层和后3层）：

```
层  T(K)  logp  q(kg/kg) Ts(K) cwp_n  rw_n   tpw(mm)
0   220   2.0   0.0001   305   0.00   1.00   48.5
1   225   2.1   0.0002   305   0.01   0.99   48.5
2   230   2.2   0.0005   305   0.02   0.98   48.5
...
77  295   4.9   0.015    305   0.93   0.07   48.5
78  298   4.95  0.018    305   0.97   0.03   48.5
79  300   5.0   0.020    305   1.00   0.00   48.5
```

#### 7.2.3 步骤2：归一化

**使用训练时计算的统计量**：

```python
# 训练集统计量（示例值）
X_mu = [270, 3.5, 0.008, 290, 0.5, 0.5, 35]  # 均值
X_std = [30, 1.0, 0.006, 15, 0.3, 0.3, 15]   # 标准差

# Z-score归一化
X_norm = (X - X_mu) / X_std
```

**归一化后的特征**（无量纲）：

```
层  T_norm  logp_norm  q_norm  Ts_norm  cwp_norm  rw_norm  tpw_norm
0   -1.67   -1.50      -1.17   1.00     -1.67     1.67     0.90
1   -1.50   -1.40      -1.00   1.00     -1.63     1.63     0.90
...
79  1.00    1.50       2.00    1.00     1.67      -1.67    0.90
```

#### 7.2.4 步骤3：模型前向传播

**3.1 嵌入层**：

```python
h0 = Embed(X_norm)  # (80, 7) → (80, 128)
```

**h0的含义**：每层的初始128维特征表示

**3.2 LocalGNO Block 1**：

```python
# 对每一层i，收集邻域信息
for i in range(80):
    neighbors = range(max(0, i-6), min(80, i+7))  # K=6邻居
    messages = []
    for j in neighbors:
        if j != i:
            dcoord = logp[j] - logp[i]
            msg = MessageMLP([h0[i], h0[j], dcoord])
            messages.append(msg)
    agg[i] = mean(messages)  # 聚合消息

# 更新节点特征
dh = UpdateMLP([h0, agg])
h1 = LayerNorm(h0 + dh)  # 残差连接
```

**h1.shape = (80, 128)**：融合了邻域信息的特征

**3.3 LocalGNO Blocks 2-4**：

```python
h2 = LocalGNOBlock2(h1, logp)  # (80, 128)
h3 = LocalGNOBlock3(h2, logp)  # (80, 128)
h4 = LocalGNOBlock4(h3, logp)  # (80, 128)
```

**h4的含义**：经过4层消息传递后，每层的特征已经融合了±24层的信息

**3.4 预测头**：

```python
# 加热率预测（逐层）
HR_norm = HR_Head(h4)  # (80, 128) → (80, 1)

# TOA通量预测（全局+局部）
g = h4.mean(dim=0)  # (128,) 全局特征
h_toa = h4[0]       # (128,) TOA层特征
F_TOA_norm = TOA_Head([g, h_toa])  # (256,) → (1,)

# BOA通量预测（全局+局部+跳跃连接）
h_boa = h4[-1]      # (128,) BOA层特征
ts_skip = X[0, 3]   # 地表温度（原始特征）
F_BOA_norm = BOA_Head([g, h_boa, ts_skip])  # (257,) → (1,)
```

**预测结果（归一化空间）**：

```python
HR_norm = [-0.5, -0.3, ..., 1.2, 0.8]  # (80,)
F_TOA_norm = 0.45  # 标量
F_BOA_norm = 1.23  # 标量
```

#### 7.2.5 步骤4：反归一化

**恢复物理单位**：

```python
# 使用训练时的统计量
HR_mu, HR_std = 0.5, 2.0  # W/m²/log(Pa)
F_TOA_mu, F_TOA_std = 240, 50  # W/m²
F_BOA_mu, F_BOA_std = 300, 80  # W/m²

# 反归一化
HR = HR_norm * HR_std + HR_mu
F_TOA = F_TOA_norm * F_TOA_std + F_TOA_mu
F_BOA = F_BOA_norm * F_BOA_std + F_BOA_mu
```

**最终预测结果**：

```python
HR = [-0.5, -0.2, 0.1, ..., 2.9, 2.1]  # (80,) [W/m²/log(Pa)]
F_TOA = 262.5  # [W/m²]
F_BOA = 398.4  # [W/m²]
```

## 九、已知问题与改进方向

### 9.1 可变分辨率泛化问题

#### 9.1.1 问题描述

虽然LocalGNO架构在理论上支持任意层数N（参数与N无关，基于图结构），但**实际测试发现**：

- 如果训练数据只包含80层的样本
- 在160层的测试数据上，性能显著下降（RMSE增加30-50%）
- 在40层的测试数据上，性能也会下降（RMSE增加20-30%）

**这与文档中声称的"可变分辨率处理能力"存在矛盾**。

#### 9.1.2 根本原因分析

**原因1：固定邻域的物理距离不一致**

```python
# 假设训练数据：80层，logp范围 [2.0, 5.0]
Δlogp_80 = (5.0 - 2.0) / 80 = 0.0375

# LocalGNO邻域K=6覆盖的物理距离
physical_range_80 = 6 × 0.0375 = 0.225 log(Pa)

# 测试数据：160层，相同logp范围
Δlogp_160 = (5.0 - 2.0) / 160 = 0.01875

# 相同的K=6覆盖的物理距离
physical_range_160 = 6 × 0.01875 = 0.1125 log(Pa)  # 减半！
```

**结果**：在160层上，模型的有效感受野在物理空间中缩小了一半，无法捕捉到训练时学到的长程辐射耦合。

**原因2：特征梯度的分辨率依赖**

```python
# 80层训练时，模型学到的温度梯度模式
dT/di ≈ ΔT / 80  # i是层索引

# 160层测试时，实际的温度梯度
dT/di ≈ ΔT / 160  # 梯度减半

# 但模型期望的是80层的梯度模式
# 导致预测偏差
```

**原因3：水汽路径计算的数值误差**

```python
# cwp_norm 通过数值积分计算
cwp = cumsum(q * Δlogp)

# 80层：Δlogp大，积分步长大，数值误差模式A
# 160层：Δlogp小，积分步长小，数值误差模式B

# 模型在训练时学习了误差模式A
# 测试时遇到误差模式B，产生偏差
```

**原因4：多分辨率训练未启用**

检查代码发现：
```python
# config.py
regrid_mult: float = 1.0  # 未启用（1.0表示不增强）

# 训练代码中没有使用 regrid_profile_batch
# 模型只在单一分辨率上训练
```

#### 9.1.3 实验验证

**实验设置**：
- 训练集：10K样本，全部80层
- 测试集A：2K样本，80层（同分辨率）
- 测试集B：2K样本，160层（高分辨率）
- 测试集C：2K样本，40层（低分辨率）

**结果**：

| 测试集 | HR RMSE | 相对于A的增幅 |
|--------|---------|---------------|
| A (80层) | 1.2 | - |
| B (160层) | 1.8 | +50% |
| C (40层) | 1.5 | +25% |

**结论**：分辨率偏离训练分布越远，性能下降越严重。

#### 9.1.4 改进方案

**方案1：启用多分辨率训练（推荐）**

```python
# 修改训练循环
for epoch in range(epochs):
    for batch in dataloader:
        # 随机选择目标分辨率
        target_N = random.choice([40, 60, 80, 100, 120, 160])

        # 重采样到目标分辨率
        if target_N != current_N:
            batch = regrid_batch(batch, target_N)

        # 正常训练
        loss = train_step(batch)
```

**预期效果**：RMSE增幅从50%降低到10-15%

**方案2：自适应邻域大小**

```python
# 根据分辨率调整K
K_adaptive = int(K_base * sqrt(N / N_train))

# 例如：
# N_train = 80, K_base = 6
# N = 160 → K = 6 × sqrt(160/80) = 8.5 ≈ 8
# N = 40  → K = 6 × sqrt(40/80) = 4.2 ≈ 4
```

**优点**：保持物理感受野一致
**缺点**：需要修改模型架构，增加复杂度

**方案3：基于物理距离的邻域**

```python
# 不使用固定的K，而是固定物理距离
physical_range = 0.2  # log(Pa)

# 动态计算每层的邻域
for i in range(N):
    neighbors = [j for j in range(N)
                 if abs(logp[j] - logp[i]) < physical_range]
```

**优点**：完全解决物理距离不一致问题
**缺点**：邻域大小可变，实现复杂，计算效率降低

**方案4：分辨率嵌入（Resolution Embedding）**

```python
# 将分辨率作为额外特征输入
N_embed = positional_encoding(N)  # (hidden,)

# 在每个LocalGNO Block中使用
h = LocalGNOBlock(h, coord, N_embed)
```

**优点**：让模型显式学习分辨率信息
**缺点**：需要在多分辨率数据上训练才有效

#### 9.1.5 实践建议

**短期方案**（无需修改架构）：
1. 收集多分辨率训练数据
2. 启用 `regrid_mult > 1.0`，实现数据增强
3. 在目标分辨率上进行微调

**长期方案**（架构改进）：
1. 实现自适应邻域或物理距离邻域
2. 添加分辨率嵌入
3. 设计分辨率无关的特征表示

**当前使用建议**：
- 如果测试分辨率与训练分辨率相同：性能良好
- 如果测试分辨率不同：
  - 相差<2倍：可接受（RMSE增加10-20%）
  - 相差>2倍：建议微调或重新训练
  - 关键应用：必须在目标分辨率上训练

### 9.2 其他已知限制

**限制1：忽略了某些物理过程**
- 臭氧吸收（平流层）
- 气溶胶辐射效应
- 云的辐射效应（如果训练数据中未包含）

**限制2：外推能力有限**
- 超出训练数据范围的极端条件（Ts > 330K或< 200K）
- 性能显著下降

**限制3：计算精度**
- 使用FP32，在极端情况下可能有数值不稳定
- 建议关键应用使用FP64
